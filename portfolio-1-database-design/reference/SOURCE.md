# Challenge data source/reference

- Origin: OWASP Juice Shop, file data/static/challenges.yml at release v20.4.0
- Downloaded: 9 November 2026
- Licence: MIT

- Used in AOT-CTF: challenge names, categories and difficulty levels seed the
  categories and challenges tables. Teams, players, submissions and solves are
  generated separately for this portfolio.

- Contents: 118 challenges in 16 categories, difficulty 1–6 stars.
 
- Converted from yaml to json (using python's YAML and JSON modules).
